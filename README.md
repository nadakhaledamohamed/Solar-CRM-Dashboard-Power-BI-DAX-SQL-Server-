# Solar-CRM-Dashboard-Power-BI-DAX-SQL-Server-
Designed and built a Power BI dashboard (PBIP) on a SQL Server solar and heat-pump sales CRM star schema. It has 96 DAX measures across three pages (Sales Overview, Operations, Trends &amp; Alerts), with month-over-month deltas and alert-limit tracking driven by the database’s own KPI and alert views.
